The shared estimator

Both production tools at Lower Granite Dam, EASE for adults and SCRAPI2 for smolts, run one estimator four times over. Written out, the skeleton is:

  1. an observed count at the dam;
  2. an inclusion or detection probability the count is only a fraction of;
  3. an expanded abundance, count divided by that probability;
  4. a composition split of the total into groups;
  5. uncertainty propagated to an interval by resampling and posterior draws.

The whole tutorial builds each piece by hand against one simulated smolt season whose truth we know. Here is the observed season.

weeks
truth$N_total   # true total wild smolts we are trying to recover
## [1] 6800

Each week has a raw trap Tally, a trap sample rate, and a guidance efficiency GE_true. The inclusion probability for the count is Ptrue = rate * GE, and abundance expands as count / Ptrue.

Complete the expansion

Write the plug-in expansion: the total wild smolts implied by the observed counts at the point (non-random) inclusion probability.

# weeks has columns Tally, rate, GE_true. Inclusion prob is rate * GE_true.
# Fill in the expansion and compare it to the truth.
ptrue <- weeks$rate * weeks$GE_true
N_hat <- ______
c(N_hat = round(N_hat), truth = truth$N_total)
# Expanded abundance is the observed count divided by its inclusion
# probability, summed over weeks: sum(count / ptrue).
ptrue <- weeks$rate * weeks$GE_true
N_hat <- sum(weeks$Tally / ptrue)
c(N_hat = round(N_hat), truth = truth$N_total)

Locate this in production. In smoltEASE/R/SCRAPI2.R, the inner estimator thetahat() forms daily abundance as passage$Tally / passage$Ptrue and sums by stratum. On the adult side, escapeLGD/R/night_fall_reascend_wc_binom.R (expand_wc_binom_night) expands a window count wc by 1 / wc_prop and by 1 / (1 - p_night). Same skeleton, different names for the probability.

Build a bootstrap from scratch

A point estimate is one number. The production interval comes from a compound bootstrap: several independent sources of uncertainty stacked into one set of B replicates. We add them one at a time and watch what each does to the interval.

Stage 1: the plug-in, no uncertainty

ptrue     <- weeks$rate * weeks$GE_true
est_daily <- round(weeks$Tally / ptrue)   # implied true weekly passage
N_plugin  <- sum(weeks$Tally / ptrue)
round(N_plugin)
## [1] 7852

Stage 2: the parametric passage-count bootstrap

The count itself is a binomial sample: of est_daily true passers, Tally were counted, with probability ptrue. Resampling that binomial is the first uncertainty source. Write one replicate.

# est_daily and ptrue are defined for you. Draw B binomial resamples of the
# weekly counts and expand each back to a total. Report the bootstrap summary.
B <- 1000
totals <- numeric(B)
for (b in seq_len(B)) {
  cstar <- ______                       # rbinom over the 6 weeks
  totals[b] <- sum(cstar / ptrue)
}
round(boot_summary(totals, truth$N_total), 1)
# rbinom is vectorised: rbinom(6, est_daily, ptrue) draws one resampled count
# per week in a single call. Put that inside the loop as cstar.
B <- 1000
totals <- numeric(B)
for (b in seq_len(B)) {
  cstar <- rbinom(6, est_daily, ptrue)
  totals[b] <- sum(cstar / ptrue)
}
round(boot_summary(totals, truth$N_total), 1)

Stage 3: one coherent GE posterior draw per replicate

GE is not known; it has a posterior. ge_draws is a 6-week by B matrix, each column a coherent season-wide draw. The rule that matters: one replicate uses one whole column, never a different column per week.

# ge_draws[, b] is this replicate's GE for all 6 weeks. weeks$rate and
# weeks$Tally are available. Build ptrue_b from column b, resample the count on
# that same basis, and expand.
B <- 1000
totals <- numeric(B)
for (b in seq_len(B)) {
  ptrue_b   <- weeks$rate * ge_draws[, b]
  est_b     <- round(weeks$Tally / ptrue_b)
  cstar     <- rbinom(6, est_b, ptrue_b)
  totals[b] <- ______
}
round(boot_summary(totals, truth$N_total), 1)
# The expansion divides the resampled count by the SAME ptrue_b that generated
# it: sum(cstar / ptrue_b).
B <- 1000
totals <- numeric(B)
for (b in seq_len(B)) {
  ptrue_b   <- weeks$rate * ge_draws[, b]
  est_b     <- round(weeks$Tally / ptrue_b)
  cstar     <- rbinom(6, est_b, ptrue_b)
  totals[b] <- sum(cstar / ptrue_b)
}
round(boot_summary(totals, truth$N_total), 1)

Locate this in production. SCRAPI2() precomputes ge_day_mat, a days-by-B matrix, and inside the bootstrap loop uses ge_day_mat[, b] for replicate b (ptrue_b <- pass[, PASSrate] * ge_day_mat[, b]). Stage 4: composition and GSI, resampled per replicate

The genotyped fish sample splits the wild total into stocks A and B. Each fish carries an inclusion weight SR; the estimator weights by 1/SR. Composition uncertainty comes from resampling the fish; GSI uncertainty comes from drawing a fresh stock-assignment column per replicate (gsi_draws).

# For one replicate: resample fish uniformly, draw GSI column b, estimate pA,
# and split a fixed wild total into stock A and stock B. Then check that the two
# stock abundances add back to the total WITHIN the replicate.
b <- 1
wild_total <- truth$N_total
idx   <- sample.int(nrow(fish), replace = TRUE)
stock <- gsi_draws[idx, b]
sr    <- fish$SR[idx]
pA_b  <- sum((1 / sr) * (stock == "A")) / sum(1 / sr)
stockA <- wild_total * pA_b
stockB <- wild_total * (1 - pA_b)
additivity_error <- ______              # should be ~0 by construction
c(stockA = round(stockA), stockB = round(stockB),
  sum = round(stockA + stockB), total = wild_total,
  additivity_error = additivity_error)
# pA_b + (1 - pA_b) = 1 exactly, so stockA + stockB - wild_total is 0 up to
# floating point: additivity_error <- (stockA + stockB) - wild_total.
b <- 1
wild_total <- truth$N_total

SCRAPI to SCRAPI2

The original SCRAPI and the current SCRAPI2 share this skeleton but differ in three decisions: whether GE and GSI are fixed or uncertain, how fish are resampled, and how the point estimate is defined. The most consequential is the resampling choice, because it interacts with the 1/SR weight already in the estimator.

Uniform vs SR-weighted resampling

The estimator weights each fish by 1/SR. The question is whether the resample should also use SR. Try both and measure coverage of the true stock-A proportion across many simulated seasons.

# coverage() re-simulates a season each iteration and builds a composition
# interval either uniformly or weighted by SR. Set `weighted` and compare.
coverage <- function(weighted, nsim = 150, B = 300) {
  hit <- logical(nsim)
  for (s in seq_len(nsim)) {
    d  <- simulate_smolt_season(seed = s, B = 1L)
    ff <- d$fish
    th <- numeric(B)
    for (b in seq_len(B)) {
      idx <- if (weighted)
        sample.int(nrow(ff), replace = TRUE, prob = ff$SR)
      else
        sample.int(nrow(ff), replace = TRUE)
      th[b] <- sum((1 / ff$SR[idx]) * (ff$stock[idx] == "A")) / sum(1 / ff$SR[idx])
    }
    ci <- quantile(th, c(.05, .95))
    hit[s] <- ci[1] <= d$truth$pA && d$truth$pA <= ci[2]
  }
  mean(hit)
}
c(uniform = coverage(FALSE), weighted = coverage(TRUE))
# You do not need to edit anything to see the effect: run it as is. The
# uniform arm keeps 1/SR honest; the weighted arm resamples proportional to SR
# AND divides by SR, so the two cancel.

Locate this in production. smoltEASE/R/SCRAPI.R (original) resamples fish with sample.int(nwk, replace = TRUE, prob = unlist(justwk$SR)) while its thetahat still divides by SR – the cancellation you just saw. smoltEASE/R/SCRAPI2.R resamples with sample.int(nrow(jw), replace = TRUE) (no prob) and keeps 1/SR and 1/True only inside the estimator. The SCRAPI2 documentation states this directly: “weighting the resample by them while also applying their inverse inside the estimator would tend to cancel the intended inverse-probability correction.”

The point estimate is the bootstrap mean

SCRAPI2 does not report the raw data evaluated once. Every one of the B rows is a full replicate, and the reported Estimate is the mean of those rows, while LCI/UCI are percentiles of the same rows.

}, numeric(1))
raw_point  <- sum(weeks$Tally / (weeks$rate * weeks$GE_true))

SCOBI to EASE

The adult estimator has its own history. Old SCOBI assumed the counting window was open the whole time (wc_prop = 1); EASE corrects for the window being closed part of each hour (wc_prop = 5/6), then expands for nighttime passage, composition, and fallback. We use one simulated adult season.

sim_ad$wc                 # weekly window counts
sim_ad$night              # nighttime-passage PIT data by stratum
sim_ad$fallback           # fallback/reascension PIT data by stratum
sim_ad$truth$N_total      # true adult escapement
## [1] 11600

SCOBI vs EASE window-count assumption

# The window is open a fraction wc_prop of the time, so the count must be
# expanded by 1/wc_prop. Compute the expanded daytime total under the old SCOBI
# assumption (wc_prop = 1) and under EASE (wc_prop = 5/6).
wc_total <- sum(sim_ad$wc$wc)
scobi <- wc_total / 1
ease  <- ______
c(raw = wc_total, scobi = round(scobi), ease = round(ease))
# EASE divides by 5/6, which multiplies the count by 6/5: ease <- wc_total / (5/6).
wc_total <- sum(sim_ad$wc$wc)
scobi <- wc_total / 1
ease  <- wc_total / (5/6)
c(raw = wc_total, scobi = round(scobi), ease = round(ease))

Nighttime passage, composition, and fallback stacked

set.seed(3)
B  <- B_boot
wc_prop <- sim_ad$wc_prop
wc_by_strat <- tapply(sim_ad$wc$wc, sim_ad$wc$stratum, sum)
nd <- sim_ad$night; fd <- sim_ad$fallback
totals <- numeric(B)
for (b in seq_len(B)) {
  # window count: parametric binomial bootstrap, expanded by 1/wc_prop
  wc_b <- vapply(seq_along(wc_by_strat), function(s)
    rbinom(1, round(wc_by_strat[s] / wc_prop), wc_prop) / wc_prop, numeric(1))
  # nighttime passage rate per stratum, binomial bootstrap, expand by 1/(1-p)
  pn_b <- rbinom(3, nd$totalPass, nd$nightPass / nd$totalPass) / nd$totalPass
  day_plus_night <- wc_b / (1 - pn_b)
  # net fallback rate per stratum, binomial bootstrap, remove reascension-net fallback
  pf_b <- rbinom(3, fd$totalPass, fd$numReascend / fd$totalPass) / fd$totalPass
  totals[b] <- sum(day_plus_night * (1 - pf_b))
}
round(boot_summary(totals, sim_ad$truth$N_total), 1)

Locate this in production. escapeLGD/R/night_fall_reascend_wc_binom.R holds expand_wc_binom_night() (window-count binomial bootstrap rbinom(boots, round(wc/wc_prop), wc_prop)/wc_prop, then 1/(1-p_night)) and nightFall() (binomial bootstrap of the nighttime rate, and a two-parameter fallback/ reascension likelihood via optimllh in fallback_reascend_likelihood.R). Composition is HNC_expand() / ascension_composition(); the pieces are multiplied together and turned into a percentile interval in apply_fallback_rates() (apply_fallback_rates_summarize.R). The EASE annual workflow (EASE-code, e.g. “SY2025 STHD Step 3”) calls this with wc_prop = 5/6 and notes wc_prop = 1 for old SCOBI.

Model diagnostics and failure modes

The compound bootstrap has characteristic ways of going wrong. Each below is a thing to check before quoting an interval.

E(1/GE) is not 1/E(GE)

one_over_mean <- sum(weeks$Tally / (weeks$rate * ge_col_means))
mean_of_one_over <- mean(vapply(seq_len(B_boot), function(b)
  sum(weeks$Tally / (weeks$rate * ge_draws[, b])), numeric(1)))

Mixing GE columns across weeks

Poor PIT sample sizes and biased GE

# night_width(n) returns the 90% interval width of the nighttime-expanded adult
# total when each stratum has n PIT tags. Try n = 50 and n = 500 and see the
# width shrink. Then set ge_bias = 1.15 to feed SCRAPI2 a GE posterior 15% too
# high and watch smolt coverage fall.
night_width <- function(n, B = 400) {
  totals <- numeric(B)
  wc_by_strat <- tapply(sim_ad$wc$wc, sim_ad$wc$stratum, sum)
  for (b in seq_len(B)) {
    pn <- rbinom(3, n, sim_ad$truth$p_night) / n
    totals[b] <- sum((wc_by_strat / sim_ad$wc_prop) / (1 - pn))
  }
  diff(quantile(totals, c(.05, .95)))
}

# A GE posterior centered 15% too high: coverage of the true total falls,
# because a confidently wrong center cannot be fixed by a wider interval.
cover_ge <- function(bias, nsim = 80, B = 200) {
  hit <- logical(nsim)
  for (s in seq_len(nsim)) {
    d <- simulate_smolt_season(seed = s, B = B)
    tot <- vapply(seq_len(B), function(b) {
      pb <- d$weeks$rate * pmin(d$ge_draws[, b] * bias, 1)
      sum(rbinom(6, round(d$weeks$Tally / pb), pb) / pb)
    }, numeric(1))
    ci <- quantile(tot, c(.05, .95))
    hit[s] <- ci[1] <= d$truth$N_total && d$truth$N_total <= ci[2]
  }
  mean(hit)
}
c(calibrated = cover_ge(1.00), biased_high = cover_ge(1.15))

Wrap-up

You rebuilt the Lower Granite escapement estimator from a plug-in expansion to the full compound SCRAPI2 bootstrap, added GE and GSI posterior draws one at a time, saw why uniform within-stratum resampling keeps the 1/SR correction honest where the original SCRAPI’s SR-weighted resample cancelled it, walked the adult side from SCOBI’s wc_prop = 1 to EASE’s 5/6 with nighttime passage and fallback, and diagnosed the characteristic failure modes.
